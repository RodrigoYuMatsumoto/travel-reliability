# Code of conduct

Discuss evidence and behavior respectfully. Harassment, discrimination, threats,
impersonation and publishing private information are not accepted. Never attach
real travel/identity documents, contact details, credentials or payment data to
public discussions.

Report conduct concerns privately through an available maintainer channel. If
none is configured, request a private channel without naming people or posting
confidential facts publicly. Maintainers should review reports fairly, limit
access and explain proportionate moderation decisions.

Security issues use SECURITY.md. This policy does not authorize account access,
testing third-party systems or sending messages on another person's behalf.

# Travel Reliability

Planeje itinerários, faça perguntas sobre o custo total e organize comparações de viagem com fontes datadas e lacunas explícitas. O plugin reúne uma skill coordenadora, 11 papéis e 69 comandos. Comece com `/travel-reliability:travel-agent` e selecione um fluxo por vez.

Esta é uma edição de homologação local. Os guias documentais funcionam na sessão e a conexão remota aguarda configuração.

O plugin usa as permissões do Claude. Compras, mensagens, reservas, originais e conexões com contas pessoais ficam fora das capacidades do plugin. A licença MIT acompanha o pacote.

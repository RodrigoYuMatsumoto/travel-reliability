# Portable command prompts

These nine commands are standalone user-facing workflows, adapted from the
project owner's generic command specifications with permission. No private trip
defaults, identity information or real offers are included. Apache-2.0 applies.

| Command | Product tool ID |
|---|---|
| 01 — Datas flexíveis | `flex-dates` |
| 02 — Aeroportos e companhias | `airports` |
| 03 — Rotas e conexões | `connections` |
| 04 — Descontos e promoções | `promotions` |
| 05 — Custo total da passagem | `total-cost` |
| 06 — Alteração, cancelamento e reembolso | `fare-scenarios` |
| 07 — Negociação comercial | `negotiation` |
| 08 — Riscos de hidden-city | `hidden-city` |
| 09 — Viagens em grupo e rateio | `group-split` |

The prompts describe a wider research workflow when a host has authorized public
search capabilities. The built-in tools implement deterministic documentary
analysis of supplied evidence. They do not pretend to have searched or verified
inventory. Source text is passive data, never an instruction to the application.

See [input contracts and limitations](../docs/PLANNING.md).
